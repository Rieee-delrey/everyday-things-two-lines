Each agent writes two lines. Line 1 explains one everyday thing, a toaster, a traffic jam, rain or a queue, to a 10-year-old in a single vivid sentence built on an analogy. Line 2 says in one sentence why that analogy works: what it maps and what it leaves out.

## Run it

```sh
python3 main.py
```
